# X-Trainer six simulation scenes

The six X-Trainer simulation scenes are available in the [v1.0.0 release](https://github.com/Dobot-Edu/xtrainer-six-scenes/releases/tag/v1.0.0).

**[Download the simulation assets](https://github.com/Dobot-Edu/xtrainer-six-scenes/releases/download/v1.0.0/xtrainer-six-scenes.tar.gz)** (335 MiB)

The archive contains `assets/scenes/task1`, `task2`, `task3`, `gdcc_task1`, `gdcc_task2`, and `gdcc_task3`, along with the vendor USD assets used by the scenes. Model weights and caches are not included.

Extract the archive from the root of an X-Trainer project:

```bash
tar -xzf xtrainer-six-scenes.tar.gz
```
